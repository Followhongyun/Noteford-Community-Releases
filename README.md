# Noteford 开源版 · macOS 下载与更新

[下载最新安装包](https://github.com/Followhongyun/Noteford-Community-Releases/releases/latest)

适用于 Apple 芯片（M1 及更新）Mac，macOS 13 或更新系统。打开 DMG，将「Noteford 开源版」拖入 Applications，然后按应用引导完成本机授权。

这是开源版的独立安装包和更新仓库，与会员开发版分开。完整 AGPL-3.0 源码附在每个 Release 的 source.zip 中，也随群内分享包提供。

恢复更新功能后的 0.1.1 会检查本仓库的正式更新，下载后在正常退出应用时安装。此前关闭更新功能的 0.1.1 需要手动安装一次新版安装包。不会把同版本重复安装或把会员版升级到开源版。
